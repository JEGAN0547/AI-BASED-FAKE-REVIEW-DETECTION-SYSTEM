ℹ️ Project Specifications & Architecture

This application was engineered for a College Final-Year / Master Project Demonstration. It combines Natural Language Processing (NLP), Machine Learning algorithms, and Explainable AI (XAI) to protect consumers and online merchants from deceptive review manipulation.

🧠 Supported Machine Learning Algorithms

  • TF-IDF Vectorizer (Unigrams & Bigrams)
  • Logistic Regression Classifier (Primary baseline model)
  • Multinomial Naive Bayes (Fast text probabilistic model)
  • Random Forest Classifier (Ensemble decision trees)
  • Support Vector Machine (SVM) (High-dimensional boundary margin)
  • Transformer / BERT Pipeline (Optional contextual embedding interface)

🔄 Preprocessing Workflow

  1. Punctuation & Noise Character Sanitization
  2. Text Lowercasing & Tokenization
  3. NLTK English Stop-word removal
  4. Numerical Feature Extraction (TF-IDF + Polarity Scores)
  5. Model Prediction & Explainable AI Factor Generation

🛡️ Security, Privacy & Ethics

All user inputs are sanitized against SQL injection and cross-site scripting (XSS). Review text is evaluated without storing unnecessary personally identifiable information (PII).
